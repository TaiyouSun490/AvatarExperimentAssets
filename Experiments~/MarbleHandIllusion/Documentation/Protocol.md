# 実験設計と原著との差

参照: Senna, Maravita, Bolognini & Parise (2014),
[The Marble-Hand Illusion, PLOS ONE 9(3): e91688](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0091688).

原著は実手への軽い打撃と石の打撃音を対応させる手続きです。実手を遮蔽し、約5分間、約1.2秒間隔で打撃します。
石の音を最初の30回で増加させ、非同期条件では800〜1600 ms遅延させます。

今回はユーザー指定による **VR派生**です。実手への打撃を短い振動に置き換え、見える仮想手を肌から大理石へ変えます。
原著の再現や、同じ錯覚が成立したとの主張はしていません。

| 項目 | 本実装 |
|---|---|
| 接触 | 右手の手背へ仮想ハンマーが接触。物理的な接触検出はない |
| 触覚 | ESP32または右XRコントローラーの短いパルス。Simulationでは送信を模擬 |
| 見た目 | UVに固定した手続き的な大理石模様と光沢。追跡座標・骨格位置は変更しない |
| 変化 | 1回目は石の音量・大理石化が0、30回目で1。条件によって視覚変化を抑える |
| 接触間隔 | 一様分布0.8〜1.6秒。原著の非周期的な実験者の打撃を自動化した設定 |
| 終了 | 最後の遅延音が終わるまで待って事後回答へ。回答中は最終の見た目を維持 |
| 質問 | 硬さ・重さ・こわばり・自分の手らしさを0〜10で実験者が入力。今回の探索用項目で、原著の尺度ではない |
| 音 | 生成した石の打撃音2種類を接触ごとに選択。空間音響、白色雑音なし |

原著の録音・バイノーラル再生・質問紙・皮膚電気反応測定を再現していません。
DelayedSoundは音だけを遅らせ、見た目と触覚を保つ比較です。UnchangedSkinは大理石化だけを除く比較です。
事後の見た目も条件間で異なるため、誘導と測定時の視覚の効果を分離する実験ではありません。
この試作には刺激停止後の回復曲線や残効を測る手続きは含めていません。

音・視覚・振動を個別にON/OFFできます。視覚OFFはハンマーと大理石化を除き、肌色の手や机は表示したままです。
振動OFFであっても接触予定表は進み、音や視覚のタイミングを他条件と対応させます。
3つの切替状態と条件は各試行のJSONに保存します。音OFF時には遅延音の待機はありません。

## 同期とログ

試行内の接触予定表をseedから事前生成します。150 ms前に音の `PlayScheduled` とESP32ワーカーの期限を予約します。
同じ接触予定時刻をハンマー軌道に使い、大理石化は接触を過ぎた最初のUnityフレームで更新します。
XRコントローラーのパルスもそのフレームから要求します。

音声バッファ・描画・シリアル送信・機械的な立ち上がりの遅れは同一ではありません。
`impact_scheduled` は予定値、`contact_frame` は描画更新の観測値、`pulse_on_written` / `pulse_off_written` はホスト送信完了です。
`worker_host_seconds` は別スレッドでの単調時計、CSVの `host_seconds` はメインスレッドがそのイベントを記録した時刻です。
刺激の物理同期を主張する前に、接触面のセンサー・マイク等で遅延を実測してください。

## 音源の来歴

`Assets/MarbleHand/Audio/MarbleTap1.wav` と `MarbleTap2.wav` は、このプロジェクト用にローカルStable Audio 3で生成しました。
原著の刺激録音でも、実測した大理石の音でもありません。seedは281028 / 281029。
無音を除去し、モノラル48 kHz PCM、ピーク−6 dBFSに加工しています。
生成条件と加工内容は隣接する `.wav.json` に記録しています。

## 検証

`Tools/Build-Marble.ps1 -ValidateOnly` は条件間の予定表一致、遅延範囲、パルスの終了・予約取消、設定の固定、
異常入力・送信故障・ハートビート停止、シーン配線、音声仕様、シェーダーと共通FPSArmの回帰を確認します。

ビルドしたexeに `--desktop --smoke-test` を渡すと、実機へ接続せず3条件を短縮実行し、
事前・事後回答の待機、音・模擬パルス、描画された大理石化、肌への復帰、追跡値の維持、CSV、予約中止を検証します。
画像と結果は `Builds/Smoke/`。検証用に作られる回答値は模擬データです。

HMDでの表示・聴感、物理振動の強さと遅延、参加者の錯覚成立はこの自動検証の対象外です。

実施済みの結果は [検証記録](Validation.md) を参照してください。
