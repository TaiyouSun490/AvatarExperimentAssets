# Newport & Gilpin (2011) の誘導手続きに準拠した VR 版

ブランチ: `codex/dht-original-protocol`。シーン: `Assets/Scenes/DHTOriginal2011VR.unity`。
既存の通常試作、HMD 視野外変更版、腱振動版は別シーンとして残しています。

## 原資料と実装範囲

- [原著本文](https://doi.org/10.1016/j.cub.2011.08.044)
- [原著 Supplement：Document S1](https://ars.els-cdn.com/content/image/1-s2.0-S096098221100950X-mmc1.pdf)
  の **Supplemental Experimental Procedures（PDF p.5）**、Figure S1（p.3）、実験1（p.6）。
- 2026-10-26 に本文と補足全文を確認。2018 年の後続研究の値ではなく、2011 年の手続きの値を採用。
- **Figure S1 の説明文には 25 mm/s、方法には 2.5 mm/s と記載の不一致がある。**
  方法と終点の数値（25秒、片手6.25cm、間隔16→28.5cm）が整合する **2.5 mm/s** を採用した。

実装対象は、原著の3条件に共通する誘導・右手への到達・報告前の表示保持です。
実験1の質問紙の提示・採点・順序無作為化、実験2の脅威刺激／皮膚電気反応、
実験3の描画課題は実装していません。原著の全実験を再現したソフトではありません。
質問紙を使う場合は補足 Table S1 を参照し、原著の条件順カウンターバランスと
参加者ごとの質問順無作為化を別途実施してください。Report 段階で外部の回答票を利用できます。

## 誘導の対応

| 項目 | 原著の値／順序 | 本実装 |
|---|---|---|
| 開始位置 | 正中から左右約8cm、机上約10cm | 16cm間隔・高さ10cmの手首代理点を開始チェック |
| 青い境界 | 外側が1.9mm/s、25秒で内側へ | 手ごとの内外の境界を3本の青い帯で表示 |
| 最終の帯の間隔 | 各手の領域が約17.5cm | 中央帯と外側帯の端の間を17.5cmにする |
| DH の手画像 | 内側へ2.5mm/s、25秒 | 描画のみ左右それぞれ6.25cmずらす |
| SH / CH の手 | 上記の適応による位置ずらしなし | オフセット0、帯の動きと25秒は共通 |
| 接地 | 帯の停止後、両手を机に置く | 実験者が物理的な接地を確認して進行 |
| フェード | 接地後、帯を7秒で消す。DHは右手も同時 | 黒い背景へ7秒かけて暗くし、終点で描画を除去 |
| CH の被覆 | 帯が消えた後、到達前に右手を黒布で覆う | 実物の布を置いたことを実験者が確認して非表示 |
| 到達 | 右手を動かさず、左手で右手に触れようとする | 実験者の合図後に開始。DHは左手の表示ずれも維持 |
| 報告 | 到達後に体験を評価 | 自動再表示せずReportで保持し、実験者操作で終了 |

6.25cm は **片手あたり**です。左右合計の位置差は12.5cmになります。
元の通常試作の片手12cm・40秒・固定リング・探索15秒の自動終了とは別設定です。
原著版は対象を右手に固定し、時間・速度のスライダーや早期消失操作を設けていません。

## VR に置き換えた箇所

原著は MIRAGE 内の実手のライブ映像です。本版は **FPSArm の手＋HMD** なので、
装置まで忠実に再現したものではなく、同じ効果や気づかれにくさを保証しません。
原著の映像遅延17ms未満を本装置の測定値として扱わないでください。

- 帯は仮想机の上の平面に置く3D表示。原著の映像上の重畳とは投影が異なる。
  帯の幅6mm・奥行42cm・青色・フェードの線形補間は本版の実装値で、原著に規定なし。
- 手の中心位置を追跡手首で代理。机合わせは接地時の手首より4cm下を机面とする近似。
  実物の机と合うか確認し、必要なら手首オフセット／机位置を調整する。
- 開始／接地の位置許容差3cm、接地後の右手移動2cmで中止する閾値は実装上の品質チェック。
  右手の不動は原著の教示だが、この数値は原著の閾値ではない。
- 原著の接地から消失への操作時点と到達合図は実験者が担当する。
  接触センサーによる自動検出ではなく、CSVには実験者による確認として記録する。
- 黒布は **実物が必要**。画面の非表示だけではCHの触覚条件を再現できない。
  布・机・他方の手による追跡遮蔽に対応できる入力方式を事前に確認する。
  コントローラーは動作確認にも使えるが、原著の素手接触とは異なる。
- 手モデルには実験者の手や布は描画しない。右手はSHなら見えたまま、CHなら実物の被覆確認後、DHなら7秒フェード後に非表示。
- Report終了後の表示復帰と中止処理はアプリの運用処理であり、原著の時定数ではない。
  身体表現の回復を測る自動プロトコルは腱振動版を参照。

## ビルドと起動

Unity 6000.5.9f1、Windows PCVR。ダウンロード済みFPSHandを利用するため追加の第三者購入は不要。
リポジトリ内の `Experiments~` を直接Unityプロジェクトとして開かず、外へコピーして使います。

```powershell
git clone --branch codex/dht-original-protocol https://github.com/TaiyouSun490/AvatarExperimentAssets.git
cd AvatarExperimentAssets/Experiments~/DisappearingHandTrick
./Tools/Import-FPSArm.ps1 -Source 'C:/path/to/FPSHand'
./Tools/Create-DHTWorkspace.ps1 -Destination 'C:/UnityProjects/DHTOriginal2011'
cd C:/UnityProjects/DHTOriginal2011
./Tools/Build-Original.ps1
```

- `Start-Original-PCVR.cmd`：HMD用。
- `Start-Original-Desktop.cmd`：自動補償運動を含むデスクトップ模擬。参加者データではない。
- Unityで開くシーンは `Assets/Scenes/DHTOriginal2011VR.unity`。
- 実行ファイルは `Builds/OriginalWindows/DHTOriginal2011.exe`。

## 実験者の操作

1. 実物の机に両手を置き **F** で机を合わせる。正中・机面・手モデルの位置を確認。
2. **B** で DH / SH / CH を選ぶ。参加者には条件を表示しない。
3. 両手を正中から各8cm、机から10cm浮かせる。**Space**で開始し、帯に触れず見える手を静止させるよう教示する。
4. 25秒後に接地を教示。両手が物理的に机に置かれたことを確認して **Space**。7秒のフェードが始まる。
5. CHの場合は実物の黒布を右手に置いて **C**。SH/DHではこの操作は不要。
6. **Space**で到達教示。右手を動かさず左手で触れさせる。必要に応じて画面の接触／空振り記録ボタンで観察を記録する。
7. 到達後 **Space**でReport。口頭評定などを外部で記録する。表示状態は維持される。
8. 報告後 **Space**で終了・表示復帰。次の試行は両手を戻し机位置を確認する。

**R / Esc**は途中中止と表示復帰。F8のHMDメニューは待機時のみ。
原著の右手静止を崩さないため、試行の進行に右ピンチやコントローラーボタンを要求しません。
デスクトップではSpaceによる接地が模擬され、**P**で到達運動を模擬できます。

## ログと検証

`%USERPROFILE%/AppData/LocalLow/AmemiyaLab/DHTOriginal2011/OriginalDhtTrials/` のCSV。
条件、段階、ソフトウェア時間、片手ずれ、帯間隔、明るさ、実手首・表示手首・左指先、
入力種別、実験者の接地／布／到達確認を記録します。消失中の表示位置は計算上の位置です。
指先を取れない場合は手首代理点と明記。デスクトップはsimulationと記録。
ログ作成失敗は開始拒否、途中失敗は中止。追跡喪失・原点変更・入力方式変更・長いフレーム停止でも中止します。

`Tools/Build-Original.ps1 -ValidateOnly` で進行・速度・手動ゲート・他版の回帰を確認。
`DHTOriginal2011.exe --desktop --smoke-test` でビルド済みプレイヤーの3条件・描画プロパティ・
到達座標・CSV・終了／中止を確認し、`Builds/OriginalSmoke/`へ結果と画像を保存します。
このテストはプロトコル時計を早送りします。HMD・実物の接触・知覚効果の検証は別途必要です。
