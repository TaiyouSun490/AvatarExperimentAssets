# DHT の HMD 視野外変更版

通常の連続ドリフト版に加えた、変化盲を狙う派生条件です。変化に気づかないことや DHT の成立を確認した実験結果ではありません。
眼球追跡は使わず、**HMD の描画視野から両手が外れたか**を判定します。視線・注視・注意を測定したとは扱いません。

## 通常版と原著の違い

通常版の 5秒基準 → 40秒で左右各12cm → 3秒保持 → 探索 → 2秒復帰は、この VR 試作の既定値です。
原著の数値を再現した設定ではなく、ずれに気づかれないことも未検証です。速度は片手3 mm/秒に相当します。

[Newport & Gilpin (2011)](https://doi.org/10.1016/j.cub.2011.08.044) は MIRAGE 装置内の実手映像を使い、右手を左手で探す際に視覚・触覚から手を失う実験です。
今回の確認では出版社の公開要約を参照できましたが、原著の補足手続きを取得できていないため、原著との数値・全手続きの一致は主張しません。

公開本文の [2018年の後続研究 §2.3](https://www.sciencedirect.com/science/article/pii/S0028393218303178) では、手を約10cm浮かせて、動くバーに触れないように位置を補償させています。
バーの動きは2.5 mm/秒・25秒で、見かけの両手間隔16cmに対して実手間隔は28cm。左右の合計差が約12cmであり、今回の「片手12cm」と同じ量ではありません。
その後、実験者が手を支持面へ下ろし、右手映像をフェードアウトして探索させます。

現在の通常版は、FPSArm、固定リング、机上の手、片手12cm、瞬時の非表示などを使う VR 向けの変更版です。
この通常版も、今回の HMD 視野外変更版も、「原著を忠実に再現した条件」として実験データを扱わないでください。
視野外変更にすると、視覚的な変化の瞬間を隠せても、見直した時の位置や運動・固有感覚から変更に気づく可能性は残ります。

## 変更のルール

既定の1回のずれは **左右それぞれ内側へ1cm**。総量は通常版と同じ片手12cmです。

1. 両手首の中心が視野内に0.25秒以上入ると、次の1回の変更を許可します。
2. 両手を覆う領域が、左右どちらの眼の描画視野からも0.25秒以上外れたら1回だけ変更します。
3. 変更後の両手の領域も視野外であることを確認します。片手でも視野内に残る、または移動先が視野内に入る場合は変更しません。
4. 外を見続けても追加のずれは起こりません。両手を見直した後、再び顔をそらすと次の1回を実行します。
5. 合計12cmに達しても、両手を見直すまでは消失に進みません。戻った後に3秒保持し、通常版と同様に片手を消して探索へ進みます。

変更のために表示手を強制的に隠す処理はありません。実際に描画視野外に出た時だけ、描画オフセットを変えます。
実手の追跡値と IK ターゲットは変更しません。表示がリングからずれて見えた場合は、参加者が実際の手を動かして合わせます。
頭を動かすタイミングは実験者が指示します。自動的な注視ターゲット提示や眼球運動の検出はありません。

視野判定は手首を中心とした既定半幅25cmの領域を使います。腕全体や遮蔽物の判定ではありません。
モデル・手のスケールを変えた場合は、見えている手と短い前腕がこの領域内に収まるよう `handBoundsRadius` を設定してください。
左右眼の視野の和集合を使い、片眼で見える位置も除外します。描画直前の頭部姿勢で判定しますが、HMD の表示遅延や再投影を実測したものではありません。

180秒以内に完了しない場合は中止します。時間切れで見えている手を強制的にずらすことはありません。
追跡喪失、リセンター、入力種別変更、フレーム停止などの通常版の中止条件も継承します。
`CONTROL` 条件では同じ回数の視野外イベントを待ち、実際のずれはゼロです。

## 導入・起動

ブランチは `codex/dht-look-away`。通常版と腱振動版のシーンも保持しています。

```powershell
git clone --branch codex/dht-look-away https://github.com/TaiyouSun490/AvatarExperimentAssets.git
cd AvatarExperimentAssets/Experiments~/DisappearingHandTrick
./Tools/Import-FPSArm.ps1 -Source 'C:/path/to/FPSHand'
./Tools/Create-DHTWorkspace.ps1 -Destination 'C:/UnityProjects/DHTLookAway'
cd C:/UnityProjects/DHTLookAway
./Tools/Build-LookAway.ps1
./Start-LookAway-Desktop.cmd
```

共通パッケージ内に入れ子になったプロジェクトの読み込み問題を避け、独立した作業コピーでビルドします。
Unity Hub には作業コピーを登録してください。DHT の2条件には ESP32 素材は不要です。
このPCでは既存の `TendonHand-Standalone` 作業コピーにビルドを追加しています。

| 条件 | シーン | ビルド |
|---|---|---|
| 通常の連続ドリフト | `DisappearingHandTrickVR.unity` | `Tools/Build.ps1` |
| HMD 視野外変更 | `DHTLookAwayVR.unity` | `Tools/Build-LookAway.ps1` |
| 腱振動 | `TendonHandVR.unity` | `Tools/Build-Tendon.ps1` |

視野外変更版の実行ファイルは `Builds/LookAwayWindows/DHTLookAway.exe`。
HMD 使用時は `Start-LookAway-PCVR.cmd`、HMD なしでは `Start-LookAway-Desktop.cmd` を使います。
後者は模擬データとして記録し、**L キーでカメラを横に向ける／戻す**操作ができます。
この派生版のプレビューでは、通常版のように実手座標を自動補償しません。矢印キーで右手、Shift＋矢印で左手を動かせます。

通常版と同じ F で机合わせ、Space で開始・探索確定、R/Esc で中止。G または PC パネルで連続ドリフト／視野外変更を試行前に選べます。
PC パネルでは1回の変更量を0.1–3cmに調整できます。待ち時間、最大試行時間、領域の大きさは Inspector の Settings で設定します。
開始時に全設定を固定し、試行中は変更しません。

## ログと検証

`%USERPROFILE%/AppData/LocalLow/AmemiyaLab/DHTLookAway/Trials/` の CSV（schema 2）。
従来の実手・表示手・探索位置に、HMD 姿勢、視野判定、移動先判定、変更回数を追加しました。
`look_away_armed`、`look_away_step`、`look_back_after_final_step`、`look_away_timeout` を記録します。
時刻はアプリの試行時計で、実際に画面が発光した時刻ではありません。通常サンプルの視野判定は直近の描画判定の値です。
変化への気づき・確信度・消失感の質問紙は別途必要です。判定結果を「気づかなかった」という報告値に置き換えません。

```powershell
./Tools/Build-LookAway.ps1 -ValidateOnly
./Builds/LookAwayWindows/DHTLookAway.exe --desktop --smoke-test
```

`Logs/look-away-validation.txt` は段階・視野・片眼可視・再許可・時間切れと通常版の回帰検証。
`Builds/LookAwaySmoke/result.txt` は実行ファイルで左右×ずれあり／なし、見ている間の固定、視野外1回1変更、実手座標維持、中止、CSV と描画の検証結果です。
同フォルダーの PNG は模擬カメラによる確認画像です。HMD 実機と参加者での検証は未実施です。
