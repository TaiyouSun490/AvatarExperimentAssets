# FPS Arm experiments

全身HumanoidやFinalIKを必要としない、一人称の左右腕用モジュール。
MeltingHandIllusionで作成した手・指追跡、左一回の腕校正、スケーリングとねじれ分散を切り出した。
名前空間は `AvatarExperiments.FpsArms`。元プロジェクトやハプティックへの依存はない。
第三者製のモデル、テクスチャ、Material、アニメーション、実験参加者の校正値は同梱しない。

## fp_male_handを使う

1. 使用権のあるモデルを自分のUnityプロジェクトへインポートし、必要なMaterialを設定する。
2. Projectでモデルを選択し、**Tools > Avatar Experiments > FPS Arms > Create profile for selected fp_male_hand**。
   保存されるProfileはボーンのパスと自分のモデル／ポーズへの参照だけ。
3. **FPS Arms > Create rig**を開き、Profileと、参加者・アバター設定ごとに固有のCalibration profile IDを指定する。
4. 既存XRカメラがあれば割り当てる。その場合、カメラの親をTracking Originとして使い、
   FPS Armsはカメラを動かさない。既存のXR制御側でカメラを追跡する。
   空欄なら、独立したTracking OriginとXRカメラを作り、FPS ArmsがHMD姿勢を反映する。
5. **Create left and right arms**で現在のシーンに追加する。シーン・Prefabの保存は通常のUnity操作で行う。
   作成操作はUndoできる。既存のシーン、Build Settings、パッケージ、XR設定を自動変更しない。
6. XR Plug-in ManagementでOpenXR、XR Handsと使用するコントローラープロファイルを有効化する。
   Tracking Originは床原点・スケール1。複数のカメラ姿勢ドライバーを同じカメラに重ねない。

旧HandAvatarの腕と同じモデル／ボーンを二重駆動しないこと。
同一シーンに全身AvatarExperimentSetupもある場合は、そのXRカメラを再利用する。
自動追加したカメラにはAudioListenerを付けないため、音声が必要ならシーン側で一つだけ設定する。

## 他のモデル

**Create > Avatar Experiments > FPS Arm Model Profile**からモデルごとのProfileを作る。
Model prefab、上腕・肘・手首と人差し指／中指／小指の付け根のルート相対パス、
指の骨・末端パスとXR Hand Jointの対応を設定する。
開き／握りのAnimationClipは任意。握りポーズがない場合、コントローラーで指を握る表現は変化しない。
素手では実測した指方向を使う。

肩→肘→手首の直接の階層、または各区間に中間ボーンが一本ある階層に対応する。
直接の階層ではその区間のねじれ分散を行わない。
左手を右モデルから作るProfileはMirror Leftを有効化する。独立した左右モデルなど
異なる構造では、コンポーネントと左右のJointBindingを手動で設定する。
fp_male_handの中手骨に見える4本は手のひらの補助ボーンなので、追跡対象は各指3区間の15区間に限定する。
自動ボーン検出のメニューはこのモデル向けであり、任意の命名規則を推測するものではない。

## 入力と校正

- Automaticは各手で物理コントローラーを優先し、未追跡側はXR Handsを使う。
  Hands Only / Controllers Onlyも指定できる。コントローラーの指はトリガー・グリップからの合成ポーズ。
- 素手：両手ピンチを1秒→離す→右人差し指を左肘へ当て、左手首と右指先を追跡可能な状態で1.5秒保持。
- コントローラー：両グリップを1秒→右コントローラーを左肘へ当て、右トリガーを0.5秒保持。
- 左の上腕長・前腕長を両腕に適用し、右の肘方向を左右反転する。肩はHMDからの推定。
  手・指は前腕の倍率を継承する。太さも拡縮される。肘の常時実測ではない。
- Inspectorの校正ボタンはPlay Modeで使用する。CキーはLegacy Input Managerが有効なときのみ。
  新Input Systemのみのプロジェクトでもピンチ、コントローラー、Inspectorから操作できる。
- Profile IDごとにPlayerPrefsへ保存する。旧MeltingHandIllusionの保存値は自動コピーしない。
  失敗・中止では前の設定を維持する。リセットはそのProfile IDの保存値だけを削除する。
- 成人用の初期妥当性範囲は区間15cm以上、合計95cm以下、モデル倍率0.6–1.6。
  肘の曲げ方向が裏返った測定はモデルの下・外側基準に補正する。
- 追跡喪失時は最後の姿勢を保持し、任意で非表示にできる。古い関節値を校正には使わない。

## リラクサー

上腕は肘のねじれを補助ボーンへ分散する。前腕は中間一本への集中を避け、
初期設定で肘側約32.5%・中間約32.5%・手首35%に分散する。
肘と手首の位置、手の向き、骨のローカル位置を維持する。
区間の補助ボーンがないモデルでは、その区間はIKと手首追従のみ。
毎回基準姿勢へ戻してからIKを解き、前フレームのねじれを積み重ねない。
完全な軟部組織や筋肉のシミュレーションではなく、見た目はモデルのスキンウェイトにも依存する。

## 検証

**FPS Arms > Run smoke tests (no hardware)**は手製の骨格を使い、左右反転、
直接／中間あり階層、手の拡縮、IK、リラクサーの端点・姿勢維持、
左右共有校正、古い追跡値の拒否を検証する。機器への出力やPlayerPrefs書き込みは行わない。
HMD装着時の見え方、実際の手のサイズ、実測校正、Questビルドは導入先で確認する。

2026-09-29: Unity 6000.5.9f1の独立した検証プロジェクトでEditorコンパイル、
既存パッケージの15チェック、新しい骨格の484姿勢を確認。
利用者所有のモデルを非配布の検証用として使用し、Profileからの設定作成、
1,924ポールサンプル、72校正回帰姿勢、2,664ねじれ姿勢、8区間拡縮ケースを確認した。
この検証はheadlessで、描画・HMD装着・機器操作の検証を含まない。
